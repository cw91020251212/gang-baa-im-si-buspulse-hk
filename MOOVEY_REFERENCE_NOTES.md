# Moovey reference notes

Source: https://moovey.net/route/KMB-74X-I-1.html

The reference route detail uses a small front-facing bus icon beside the station/timeline path for near-arrival or in-transit status, rather than a wide text badge occupying the right side of the station row. Its station rows have generous vertical breathing room, with the timeline line and status marker close together while station names remain visually separate. The route header keeps three ETA cards compact and the station timeline below remains readable.

Implementation implication: use a small accessible front-bus glyph or CSS bus-front mark positioned in the timeline column/marker rail; avoid adding a wide right-side label that compresses station names. Increase stop-row vertical spacing moderately and place inferred in-transit markers on the rail between stations. Preserve explicit non-GPS wording in supporting text.
